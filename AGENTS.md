# AGENTS.md

Notes app: Next.js + React 19 canvas of realtime sticky notes, backed by Firebase (Firestore via REST routes, Realtime Database for stars/presence), Firebase Auth, Tailwind CSS v4.

## Agent skills

### Issue tracker

### Domain docs

Single-context layout: root `CONTEXT.md` plus `docs/adr/`. See `docs/agents/domain.md`.
