# Live Notes

Live Notes is a shared board where people leave notes under one consistent public identity.

## Language

**Username**:
The unique public name of a signed-in person. The app uses it everywhere that person's identity appears.
_Avoid_: Display name, nickname

**Profile**:
The public identity of a signed-in person, made up of their username and optional account photo.
_Avoid_: User record, account details

**Author snapshot**:
The username and photo remembered on a note so its author remains recognizable when the live Profile is unavailable.
_Avoid_: Note owner

**Presence**:
A temporary record that shows a signed-in person or anonymous guest is currently on the board.
_Avoid_: Profile, user status
